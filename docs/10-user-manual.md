# 用户手册

本文面向系统使用者（发送指令的终端用户和管理台管理员），说明指令格式、任务
状态和管理台操作。安装过程见 [`09-installation-guide.md`](09-installation-guide.md)。

- 编写日期：2026-09-24
- 当前真实微信/站点链路未启用；本手册描述的能力在模拟环境下可完整操作。

## 1. 角色与使用前提

| 角色 | 能做什么 |
|---|---|
| 终端用户 | 从受信任聊天账号向代理机发送指令，接收回答或商品比较结果 |
| 管理员 | 通过管理台查看任务与节点、取消任务、重新执行、紧急停止、查看统计 |

终端用户必须满足两个前提，否则指令不会执行：

1. 发送账号在管理员配置的受信任白名单（`TRUSTED_SENDER_IDS`）内。
2. 消息以指定命令前缀（默认 `#助手`）开头。

普通聊天消息和非白名单消息会被忽略或拒绝，不产生任务。

## 2. 指令格式

### 2.1 AI 问答

```text
#助手 解释一下什么是零信任网络
```

系统把问题交给 AI 页面，取得回答后回复到原会话。

### 2.2 商品查询

```text
#助手 搜索 300 元以内的无线鼠标，比较三款
```

必需要素：商品关键词和最高预算。可选要素：候选数量、偏好（如“静音”“静音”）。
若缺少必要参数，任务进入“待补充”，系统回复缺失字段清单，用户补充后继续。

### 2.3 不会被执行的请求

支付、下单、转账、发红包、索要验证码/Cookie、要求绕过验证码或风控等请求会被
策略直接拒绝（`POLICY_DENIED`），系统不会操作任何页面。网页内容只被当作数据，
其中嵌入的指令不会被执行。

## 3. 任务状态

| 状态 | 含义 | 用户侧表现 |
|---|---|---|
| `RECEIVED` 已接收 | 消息通过校验，任务已创建 | 等待处理 |
| `PLANNED` 已规划 | 已生成固定执行步骤 | 等待执行 |
| `WAITING_FOR_INPUT` 待补充 | 缺少必要参数 | 收到缺失字段提示，可补充 |
| `RUNNING` 执行中 | 工作流正在执行 | 等待结果 |
| `WAITING_FOR_HUMAN` 待人工 | 登录失效或出现验证码 | 暂停等待管理员处理，不自动绕过 |
| `SUCCEEDED` 已成功 | 闭环完成 | 收到回答/商品比较 |
| `FAILED` 已失败 | 执行失败 | 管理员可在管理台重新执行 |
| `CANCELLED` 已取消 | 被用户取消或急停中止 | 不再继续执行 |
| `REJECTED` 已拒绝 | 策略拒绝 | 收到拒绝提示 |
| `INTERRUPTED` 已中断 | Agent 断线或服务重启导致中断 | 管理员确认后可重新执行 |

## 4. 管理台操作

管理台地址：`http://127.0.0.1:4173`，含三个视图，每 3 秒自动刷新。

### 4.1 任务监控

- 左侧任务列表：点击任一任务查看详情；详情含执行步骤时间线和结果。
- 状态筛选：全部、执行中、待补充、待人工、已成功、已失败、已取消、已中断。
- 取消任务：选中非终态任务后点击“取消任务”，后续步骤不再执行。
- 重新执行：仅 `FAILED`（已失败）和 `INTERRUPTED`（已中断）任务显示该按钮；
  系统基于原请求创建一个**新任务**，不会覆盖原记录。中断任务不会自动重放。

### 4.2 执行节点

- 展示所有已注册 Agent 的名称、版本、能力、最近心跳和状态
  （在线/离线/已暂停/执行中）。
- 状态由心跳驱动，超过心跳窗口自动转为离线。
- 无节点时显示空状态提示。

### 4.3 紧急停止

顶栏“紧急停止”按钮对所有节点生效，使输入立即停止并暂停接单。为防误触，
采用**两次点击确认**：

1. 第一次点击，按钮进入确认态（显示“再次点击确认急停”，4 秒有效）。
2. 4 秒内第二次点击才真正触发；超时自动取消，需重新开始。

触发后运行中任务转为取消，按钮恢复常态。真实 Windows 执行器上“2 秒内释放
全部输入”的指标尚未实测。

### 4.4 统计看板

展示总体和按类型（AI 问答、商品查询）的：

- 总任务数、闭环完成数、成功数、失败数、成功率。
- 平均耗时、P50/P95。
- 总体终态错误分布（条形展示）。

口径说明：

- 成功率分母为闭环完成数（成功 + 失败）；取消、拒绝、中断不计入；没有闭环
  完成时成功率显示为 `--`（接口返回 `null`）。
- 耗时按 `updatedAt - createdAt` 计算，分位数采用 nearest-rank 方法。
- 看板顶部有固定声明：**由测试夹具或模拟适配器产生的数据不代表真实站点
  成功率**。

接口支持按类型和时间窗过滤：`GET /api/v1/statistics?type=AI_QUESTION&from=...&to=...`。

## 5. 异常场景怎么办

| 场景 | 系统行为 | 处理方式 |
|---|---|---|
| 参数缺失 | 转“待补充”，回复缺失字段 | 用户在原会话补充信息 |
| 登录失效 | 转“待人工”，不循环点击 | 管理员在执行机完成登录 |
| 出现验证码 | 暂停并通知，不绕过 | 管理员人工完成验证 |
| Agent 断线 | 任务转“已中断”，不自动重发 | 管理员排查后点“重新执行” |
| 服务重启 | 活动任务转“已中断” | 恢复节点连接后手动重新执行 |
| 现场断网 | 在线演示不可用 | 改用 `/offline-demo.html` 离线夹具，见演示脚本 |

## 6. 离线夹具

离线夹具是自包含静态页：`apps/operator-web/public/offline-demo.html`，可断网
通过 `file://` 直接打开，含六个场景：系统就绪、AI 问答闭环、商品查询闭环、
危险动作策略拒绝、紧急停止、实验统计（夹具样本）。

页面顶部和水印始终标注“测试夹具”，所有数据均为夹具数据，不代表真实软件或
真实站点结果。

## 7. 使用边界提醒

- 服务只监听本机回环地址，管理台与 Agent 均应在同一台执行机上使用。
- 系统不存储也不应在配置中出现账号密码、Cookie 等凭据。
- 日志对邮箱、密钥、长数字等做脱敏；任务详情中不会出现完整敏感信息。
- 当前适配器未接入真实环境时，任务返回 `ADAPTER_NOT_CONFIGURED`，桌面动作
  返回 `NOT_IMPLEMENTED`，均为预期行为，不是故障。
