# 实施计划

## 1. 开发策略

先验证最不确定的 UI 可自动化性，再搭建完整工程。若微信、购物网站或 AI 页面无法稳定定位，越早发现越能调整演示目标。

实际进度以 [`08-development-status.md`](08-development-status.md) 为准。允许在没有
Windows 环境时使用 Fake/Stub 提前完成跨平台工程骨架，但这不替代 M0，也不能据此
判定 M1 通过退出验收。

## 2. 里程碑

### M0：技术 Spike（2026-09-24 至 2026-10-07）

目标：证明关键路径可行，不追求工程完整性。

- 在目标 Windows 11 机器安装 .NET 10 SDK、Node.js 24 LTS、Git。
- 用 FlaUI Inspector 验证微信会话列表、消息区、输入框、发送按钮。
- 编写一次性 PoC：打开记事本、输入文本、读取剪贴板、截图。
- 用 Playwright 录制并验证一个 AI 页面问答。
- 用 Playwright 验证一个购物网站搜索并提取 3 个商品。
- 记录分辨率、DPI、软件版本、登录和验证码行为。

退出标准：三条 PoC 路径至少两条稳定重复 20 次，成功率不低于 90%；微信收发必须通过。

### M1：工程骨架（2026-10-08 至 2026-10-20）

- 创建 npm workspaces、TypeScript 严格配置和 .NET solution。
- 实现 Control Server 健康检查、SQLite migration、结构化日志。
- 定义 WebSocket 契约和 Agent 注册/心跳。
- 实现 C# Agent 连接、指令去重、取消和紧急停止。
- 建立 CI：Node lint/typecheck/test，.NET format/build/test。

退出标准：Agent 连续运行 2 小时保持连接；服务重启后能恢复连接；契约测试通过。

### M2：AI 问答闭环（2026-10-21 至 2026-11-05）

- 实现白名单联系人和命令前缀。
- 实现微信新消息检测与去重。
- 实现规则意图解析和 AI 问答工作流。
- 实现 AI 页面 Adapter。
- 将回答回复到原会话。
- 在管理台展示任务和步骤。

退出标准：标准问答场景连续 20 次成功率不低于 90%，重复消息不重复执行。

### M3：商品查询闭环（2026-11-06 至 2026-11-20）

- 实现购物请求参数解析。
- 实现站点搜索、筛选与候选抽取 Adapter。
- 实现确定性评分和三款商品比较格式。
- 增加价格、链接、采集时间校验。
- 增加登录失效和验证码人工接管状态。

退出标准：固定测试商品集的字段抽取准确率不低于 95%，预算约束不得失效。

### M4：可靠性与安全（2026-11-21 至 2026-12-20）

- 完成任务超时、取消、有限重试和中断恢复。
- 增加前台窗口双重校验、动作有效期和策略双检。
- 完成日志脱敏、截图保留和自动清理。
- 增加适配器版本与页面变化诊断。
- 覆盖异常流程和长时间运行测试。

退出标准：禁止动作拦截率 100%；紧急停止在 2 秒内生效；8 小时稳定性测试无失控输入。

### M5：答辩准备（2026-12-21 至 2027-01-17）

- 固化目标软件版本和演示账号。
- 准备离线测试页与降级演示，避免现场网络导致完全不可演示。
- 收集成功率、平均耗时、错误分布等实验数据。
- 完成安装手册、用户手册、设计说明和答辩演示脚本。
- 录制完整闭环视频作为备份。

## 4. 团队分工建议

三人团队：

- A：C# Desktop Agent、微信 Adapter、Windows 安全控制。
- B：Node Control Server、状态机、数据库、契约。
- C：Playwright 站点 Adapter、Vue 管理台、端到端测试。

接口契约与主路径测试由三人共同评审，避免模块各自可运行但无法联调。

## 5. Definition of Done

每个任务完成必须满足：

1. 有正常、失败、超时或取消中的相关测试。
2. 错误使用稳定错误码，日志含任务关联 ID。
3. 不新增通用脚本执行或越权能力。
4. UI 定位器集中在 Adapter 内。
5. 文档或契约与行为同步。
6. 在目标 Windows 机器完成真实验证。
7. Code Review 后才能进入主分支。
